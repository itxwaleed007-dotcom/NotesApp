# 📝 My Notes App

A clean and simple Android notes app built with **Java** and **Android Studio**. Notes are saved on the device, so they stay even after the app is closed.

## ✨ Features

- Add new notes with a title and content
- View all notes in a clean card list (newest first)
- Tap a note to edit it
- Delete notes with a confirmation pop-up
- Notes saved locally using SQLite
- Empty-state message when there are no notes
- Custom app icon and name

## 🛠 Tech Stack

- Java
- Android Studio
- SQLite (SQLiteOpenHelper)
- RecyclerView with a custom Adapter
- Activities and Intents
- XML layouts (CardView, FloatingActionButton)
